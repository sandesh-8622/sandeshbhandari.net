# sandeshbhandari.net

My personal website. Built with [Astro](https://astro.build).

## Setup

```
npm install
npm run sync
npm run dev
```

## Environment Variables

Create a `.env` file:

```
CONTENTFUL_SPACE_ID=your_space_id
CONTENTFUL_API_KEY=your_delivery_api_key
```

## Commands

| Command | Action |
|---|---|
| `npm run dev` | Start dev server |
| `npm run sync` | Pull blogs from Contentful |
| `npm run build` | Build for production |

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `g h` | Home |
| `g a` | About |
| `g b` | Blog |
| `g p` | Photography |
| `g w` | Work |
| `g g` | Scroll to top |
| `j` / `k` | Navigate lists |
| `/` | Search |
| `Ctrl /` | Shortcuts help |
| `Esc` | Go back |
